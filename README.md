## 📋 О проекте

Автоматическая генерация профессиональных коммерческих предложений в форматах **DOCX** и **PDF**.

## ✨ Возможности

| Функция | Описание |
|---------|----------|
| 📄 DOCX | Редактируемые документы Word |
| 📑 PDF | Профессиональные PDF файлы |
| 🎨 4 шаблона | Бизнес, Современный, Элегантный, Минимализм |
| 💰 Скидки | Автоматический расчет |
| 🖼️ Логотип | Поддержка логотипа |
